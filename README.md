# pages-wap-leisu

## 项目简介

`pages-wap-leisu` 是一个用于归档和发布多个独立 HTML 页面的仓库。本仓库旨在以静态文件的形式保存并展示一系列独立的前端页面，这些页面可能涵盖了不同的主题、功能或设计示例，不针对任何特定域名或网站。

## 目录说明

```
pages-wap-leisu/
├── pages/          # 存放所有独立 HTML 页面文件
├── assets/         # 页面依赖的公共资源（样式、脚本、图片等）
└── README.md       # 本文件
```

- `pages/` 目录下每个 HTML 文件为一个独立页面，文件名即页面标识。
- `assets/` 目录存放页面共享的静态资源文件，按类型或用途组织。

## 页面归档说明

本仓库中的每个 HTML 页面均为独立归档，可直接通过浏览器打开访问。页面内容、样式与功能均保持原始状态，不依赖外部服务或动态后端。归档目的为记录、展示或后续参考，不作商业用途。

## 使用方式

1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/your-username/pages-wap-leisu.git
   ```
2. 使用浏览器打开 `pages/` 目录下的任意 HTML 文件即可查看页面内容。
3. 如需部署到 GitHub Pages 或其他静态托管服务，可将 `pages/` 作为站点根目录。
